# ToDoList 학습 프로젝트

DB 접속 값은 `.env.example`의 이름에 맞춰 **프로세스 환경변수**로 지정합니다. `TODO_DB_URL_PREFIX`는 데이터베이스 이름 앞까지의 JDBC URL이며 `/`로 끝납니다. 기존처럼 작업 데이터는 `todolist`, 사용자 데이터는 `userlist` 데이터베이스에 연결합니다. Java가 `.env` 파일을 자동으로 읽지는 않으므로 IDE 실행 설정이나 셸에서 주입합니다. 실제 `.env`와 빌드 산출물 `bin/`은 커밋하지 않습니다.

소스에서 다시 빌드하고 실행 시 MySQL Connector/J를 클래스 경로에 추가합니다. 추적을 해제한 기존 `bin/`의 클래스는 이전 접속 정보를 포함하므로 실행하거나 배포하지 않습니다.

이 프로젝트는 데스크톱 클라이언트가 DB에 직접 접속하고 사용자 비밀번호를 평문 비교하는 과거 학습 코드입니다. 개인 로컬의 폐기 가능한 학습 DB에만 사용하며 실제 계정 비밀번호를 재사용하지 않습니다. 공개 서비스로 재사용하려면 별도 인증 서버와 비밀번호 해싱 설계가 필요합니다.

기존 공개 자격 증명은 사용자 확인상 폐기되었거나 서비스가 삭제됐습니다. 현재 소스 정리는 Git 이력의 값을 지우거나 자격 증명을 폐기하는 작업을 대신하지 않습니다.
